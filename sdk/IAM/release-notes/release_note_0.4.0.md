# IAM リリースノート

## v0.4.0

コンテキスト情報からメンバーコードを取得できるようになりました。  
既存の公開 API を削除・変更するものではないため、既存コードを修正せずに SDK を更新できます。  
メンバーコードを利用する場合は、レスポンスの `MemberCode` を参照してください。  

## 追加・改善

### コンテキスト情報からメンバーコードを取得

コンテキスト取得 API（GET /auth/context）のレスポンスにメンバーコードが含まれるようになりました。  

- 変更前: レスポンスからメンバーコードを SDK のプロパティとして取得できない
- 変更後: レスポンスの `MemberCode` からメンバーコードを取得できる

```csharp
// 操作例
ContextGetResponse context = await client.Auth.Context.GetAsync();
string memberCode = context.MemberCode;
```

影響:

- 既存の利用コードへの変更は必要ありません。
- メンバーコードを利用する処理では、コンテキスト取得 API のレスポンスに `MemberCode` が設定されることを確認してください。

移行の考え方:

- メンバーコードが必要な場合は、コンテキスト取得 API のレスポンスにある `MemberCode` を利用してください。
- メンバーコードを利用しない場合は、既存の実装を変更する必要はありません。

## 仕様追随

- IAM API の仕様更新を反映しました。
- SDK のバージョンを `0.4.0` に更新しました。

## 利用者向け確認ポイント

1. 利用するパッケージが IAM SDK `0.4.0` へ更新されていることを確認してください。
2. メンバーコードを利用する処理では、コンテキスト取得 API のレスポンスから `MemberCode` を参照してください。
3. 既存のコンテキスト取得処理に変更がない場合は、更新後も従来どおり動作することを確認してください。
